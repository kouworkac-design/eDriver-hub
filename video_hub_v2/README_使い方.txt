■動画の登録
1. 「動画を追加・管理」を開く
2. YouTube動画URLとタイトルを入力
3. タグを1つ以上選択（複数選択可）
4. 「動画を追加」を押す
YouTube通常URL、youtu.be URL、Shorts URLに対応。動画はサムネイルを押すとページ内で再生します。
「新着動画」は自動枠なのでタグ選択は不要です。ほかのカテゴリーにチェックを付けた動画が新着一覧にも表示されます。

■大切：共有サイトへ反映する方法
このサイトはGitHub Pagesなどの静的ホスティング向けです。管理フォームから追加した内容は、まず操作したブラウザ内に保存されます。これだけでは他の閲覧者には反映されません。
全員に公開するには：
1. 「登録データを書き出す」を押し、videos.jsonを保存
2. GitHubのサイト用リポジトリにあるvideos.jsonを置き換える（初回は同梱のvideos.jsonをアップロード）
3. index.htmlとvideos.jsonが同じ公開フォルダにあることを確認
4. GitHub Pagesの更新後、サイトを再読み込み
GitHub Pagesは無料で使えます。サイトのURLを知っている人は閲覧できます。

■管理画面の注意
管理画面はログイン・パスワード保護されていません。公開状態のままでは閲覧者も登録・編集操作ができる可能性があります。管理者だけが安全に追加・編集できる運用にするには、認証機能とデータベースを追加する必要があります。今のファイルはまず見た目と登録フローを試すための試作版です。

■YouTubeプレイリストについて
現状は動画を1本ずつ登録する仕様です。プレイリストURLを1つ貼って丸ごと表示する機能ではありません。必要ならプレイリスト一括埋め込みにも改良できます。
限定公開動画のURLは共有先に転送される可能性があります。機密情報・社外秘動画は掲載しないでください。
